# A4.6 — Joint F1/F2 + strict ring-slide *formal* quotient

**Status:** exact theorem and replayable finite search on an explicitly
restricted presentation-rewrite system, **not** a full
Bonahon–Siebenmann isotopy classifier.

## Primary-source boundary

Bonahon–Siebenmann §§12.4,12.5,12.7.1,12.7.3 distinguishes:

* **F1/F2:** genuine source-defined tangle flips, reversing certain
  cyclic orders and applying ζ or ξ/η to all affected *free-bond*
  V4 labels;
* **R±:** the actual source's signed **location-changing** ring moves,
  which preserve the three-vertex ±2—±1—±2 cap;
* **§12.5 ring abbreviation:** a different, **lossy** representation
  change, erasing suitable caps and retaining their number at
  surviving attachment vertices.

The A4.1 **formal slide** is more restricted than the published
R± transformation and has **not** been independently certified
against a plumbing/Conway diagram. A4.2/A4.3 supplies its
terminating rooted normal form. A4.4 has verified the F1/F2
commuting squares under our strict abbreviation.

Primary monograph:
https://dornsife.usc.edu/francis-bonahon/wp-content/uploads/sites/205/2023/06/BonSieb-compressed.pdf
(§12.4 printed p.155; §12.5 pp.157–158; §12.7.1 p.166;
§12.7.3 p.167).

## The declared formal equivalence

Let `T` be a V4-labelled weighted planar tree with a chosen
**surviving free root bond** f, signed ±2—±1—±2 pendant ring caps,
and the following *strict* guards:

1. **Every** necessary source-pattern ring signature is recognized
   by A2.6's strict cap matcher and all signs match one s=±1;
2. All attachment base sectors are zero, including those not
   adjacent to a cap stem;
3. No cap is attached to another ring center, including opposite
   signs, and every cap's center weight occupies the supported wedge;
4. Rooted cyclic bond/sector arrays can be aligned with the incoming
   parent bond at slot zero without a cap occupying that slot; and
5. Every free bond has an explicit V4 label, with f marked.

The only moves admitted are:

- **F1**, source-defined global V4 tangle flip;
- **F2_f**, source-defined even-parity V4 tangle flip pivoted at the
  vertex incident to f;
- **R_formal**, one A4.1 adjacent swap of a whole ring attachment
  stem and an ordinary nonanchor bond at its existing base.

The last operation is a formal planar presentation rewrite, **not
independently certified R± tangle isotopy**. It never deletes a
ring subtree, changes sector weights, or alters a V4 label.

## Theorem A4.6.1 — a two-stage complete normal form for the
## restricted formal presentation relation

Denote by `N_R` the rooted cyclic-alignment and stable
`RO→OR` sorting certificate from A4.2/A4.3. Let `G_f`
be the four-element group generated by source F1 and F2_f.

Since the root V4 label changes respectively by the four distinct
Klein-group elements `0,ζ,ξ,η`, exactly **one** element of each
`G_f` orbit has root label zero. Call that element `T_g`.

Define

```text
N_joint(T) = N_R(T_g).
K_joint(T) = rooted-presentation-code(N_joint(T)).
```

**Claim (restricted formal domain).** The code `K_joint` is constant
on all admitted F1/F2_f/formal-slide moves. On a fixed residual
rooted weighted plane-tree skeleton with identical signed cap
subtrees at all-zero-sector bases, it is **complete** for the
declared formal move equivalence.

**Proof.** The F1/F2 group has four commuting actions and the
root-label-identity element is unique: applying either generator
only permutes these four choices. Therefore `T_g` is the same
presentation modulo marked plane-tree isomorphism before and
after a flip.

A strict adjacent ring slide does not alter any V4 labels, vertex
weights, or the incidence graph. F1 and F2 reflect selected cyclic
orders and preserve the strict signed cap's local wedge pattern
(the weight has sectors `(0,s,0)`, which is reflection symmetric).
Reflecting a base cyclic order sends an adjacent `R/O`
interchange to another adjacent `R/O` interchange, with the
same noncap anchor. Thus F1/F2 conjugate supported slide paths
to supported slide paths, and the root gauge of two slide-equivalent
presentations is itself slide-equivalent.

A4.2 orients the slides `RO→OR` and proves termination
and unique normal form using the strictly decreasing inversion
count. Rooted cyclic alignment (A4.3) makes this independent of
arbitrary stored slot starts. Consequently `K_joint` agrees
before and after each admitted move.

For **completeness on the declared fixed skeleton and cap-type
subclass**, equality of normalized rooted codes yields a marked
presentation isomorphism between the two normalized forms.
Each input reaches its normalized form by one of the four
source-defined flips, the rooted cyclic-isomorphism alignment,
and replayable formal slides. Reverse the second path to connect
the inputs. No claim is made about a broader canonical or
topological quotient. □

### Theorem A4.6.2 — exact four-sheeted joint formal orbits

In the A3.2 corolla with d>=3 V4 free bonds and r indistinguishable
signed ring caps at one all-zero-sector base, the formal slide
orbit contains `binom(d+r-1,r)` presentation states.
The joint F1/F2_f + formal-slide orbit has exactly

```text
4 * binom(d+r-1,r)
```

**indexed presentation states**, because:

1. Every flip preserves the strict ring pattern;
2. Reflection conjugates adjacent R/O swaps, so each of the four
   V4 sheets has the same placement orbit size;
3. The sheets cannot overlap: their marked root labels differ by
   each of the four elements of V4.

For the A3.2 k-base bounded-valence path, the **full** A4.1 formal
slide orbit was proved to have `4*3^(k-2)` indexed placements
(k>=2; the original 2^k binary family is a strict subfamily).
Thus the joint formal orbit has

```text
16*3^(k-2)
```

indexed states.

These are **counts of stored, indexed presentation objects under
a restricted formal action**. They do not count genuine tangles,
crossing-number strata or ambient-isotopy classes.

## The independent abbreviated quotient check

Define the restricted §12.5 abstraction `A_s(T)` and the
A4.4 root-V4-gauged abbreviated flip-orbit key

```text
K_abbr(T) = abbreviated_flip_orbit_key(A_s(T),f).
```

By A4.4 equivariance, each F1 and F2_f preserves `K_abbr`.
By A4.1's zero-sector adjacency guard, every formal slide
preserves the abbreviated **representation** unchanged.

Therefore `K_abbr` is invariant under the **entire declared
joint formal action**. On the fixed residual skeleton and
identical-cap subclass, its equality criterion agrees with that of
`K_joint`: both discard cap positions, retain per-base ring
numbers, ordinary branch order, weighted sector data and every
marked free-bond V4 label, and divide by the same four-element
flip subgroup.

This is a comparison of **two independently computed formal
presentation quotients**, not a topological equivalence
certificate.

## Software and verification

`arborescent/flip_ring_quotient.py` implements:

- `normalize_flip_ring`: a verified two-stage certificate with
  explicit F1/F2 group choice and replay of rooted formal slides;
- `flip_ring_normal_key`: the stable rooted presentation code;
- `JointMove` for typed F1, F2_f and ring-slide steps;
- `apply_joint`, `joint_successors`, and bounded
  `explore_joint` BFS; and
- `JointTrace.verify` with shortest-witness predecessor reconstruction.

The finite BFS marks `complete=False` on a state limit; a
truncated run is never used to claim a class count.

Regressions in `tests/test_flip_ring_quotient.py` compare the
joint group/move BFS against **both independent keys**, test both
signs, several corolla sizes and k=2,3 bounded-valence paths,
replay certificates, arbitrary vertex storage rotation, nonroot
V4 discrimination, invalid moves and explicit cutoff reports.
